1. Synthèse exécutive & porteur de projet

MOTO Editor est un IDE 100 % local (sans cloud, sans Electron) qui reproduit les capacités de Zed avec une interface minimaliste type Claude Code, une IA locale et 100+ paramètres. Le projet est déjà construit : 0 erreur de build, 3 docks modulaires, terminal réel, 20 agents IA, sécurité Ed25519.

Le porteur de projet

  • Développeur solo (fondateur), temps partiel (15–20 h/sem.), motivé par le produit.
  • Levier décisif : 3 IA d'assistance (Claude Code, Qwen, Copilot) → productivité ×2–3, équivalent d'une petite équipe sans salaire.
  • Compétences couvertes : C#/.NET, MAUI/WinUI3, sécurité, packaging ; à compléter : marketing (compensé par le « build in public »).

Principes bootstrap

  • Aucune levée de fonds, aucune dette, aucun salarié.
  • Coûts fixes < 20 €/mois grâce aux tiers gratuits (GitHub, GitHub Pages/Releases).
  • Rentabilité dès le 1ᵉ abonné Pro ; le projet ne peut pas « brûler » de cash.
  • Croissance organique uniquement ; le temps remplace l'argent.

2. Proposition de valeur & niche

Pour qui ?

  • Indés & petites équipes sensibles au coût et à la légèreté.
  • Power users voulant 100+ réglages sans chaos d'extensions.
  • Profils privacy : code jamais envoyé dans le cloud.
  • Utilisateurs attentifs à l'accessibilité (WCAG).

Quel problème ?

  • VS Code lourd, gourmand en mémoire, interface dense.
  • Cursor/Copilot = code envoyé dans le cloud.
  • Zed jeune, Windows perfectible, accessibilité faible.
  • JetBrains verrouillés et payants.

Pourquoi nous ?

  • Local-first : IA locale (Ollama/ONNX), rien ne sort de la machine.
  • Natif .NET/MAUI : léger et rapide sans Electron.
  • Minimalisme + profondeur (100+ paramètres data-driven).
  • Histoire forte : « 1 dev + 3 IA construisent un Zed-like ».

Positionnement : ne pas attaquer VS Code frontalement ; créer la catégorie « IDE minimaliste, local & accessible ». Message : « La puissance d'un IDE moderne, la légèreté d'un éditeur, la confidentialité du local. »

4. Modèle économique & tarification

Modèle open source + freemium (validé par Zed et Cursor) : le gratuit construit l'adoption et la confiance ; le payant finance le fondateur. Aucun paywall sur l'essentiel — la doctrine « pas d'UI factice » s'applique aussi au business.

Pourquoi ça marche en bootstrap

Élasticité favorable

  • Coût marginal d'un utilisateur gratuit ≈ 0 (hébergement GitHub gratuit).
  • 10 €/mois = prix psychologique « soutien de créateur », pas un achat entreprise.
  • 96 €/an prépayé = trésorerie d'avance, sans facturation complexe.

Garde-fous

  • Le gratuit reste complet à vie (crédibilité open source, évite le fork hostile).
  • Pro = service & priorité, jamais une fonctionnalité vitale verrouillée.
  • Pas de publicité, pas de revente de données (cohérent privacy-first).

6.3 Seuils & lecture

Seuil de rentabilité

  • Coûts fixes ≈ 15 €/mois → rentable dès 2 abonnés Pro.
  • Équivalent temps partiel (1 500 €/mois) atteint vers an 3 (≈ 300 Pro).
  • Aucun scénario de faillite : le pire cas = quelques centaines € perdus.

Sensibilité

  • Conversion 1,5 % au lieu de 2,5 % en an 3 → CA ≈ 27 k€ : reste viable.
  • Un « post viral » (HN/PH) peut avancer l'an 2 de 6 mois.
  • Le modèle encaisse un choc : pas de salariés, pas de locaux, pas de stock.

7. Juridique, fiscal & risques

Structure & fiscal (France)

  • Micro-entreprise : création gratuite en ligne ; cotisations ≈ 21 % du CA encaissé ; pas de CA = pas de charges.
  • Franchise de TVA (≈ 39 k€) : pas de TVA à facturer tant que le seuil n'est pas franchi.
  • Ouverture d'un compte bancaire dédié (obligatoire au-delà de 10 k€/an pendant 2 ans).
  • Évolution possible vers SASU/EURL en an 3 si CA > 40 k€ (à ré-arbitrer).

Licence & propriété

  • GPL-3.0 pour le cœur (comme Zed) : adoption + protection contre l'appropriation.
  • Marques/logo : dépôt INPI reporté (an 2) ; en attendant, copyright simple.
  • CLA léger pour les contributions externes (garder le contrôle).
  • RGPD : produit 100 % local = quasi aucune donnée collectée → politique de confidentialité courte, argument commercial.

    Conclusion

    Ce business plan assume une vérité simple : un solo ne gagne pas par l'argent, mais par le temps, la niche et l'histoire. Avec < 500 € de mise, < 20 €/mois de coûts et un produit déjà construit, le risque financier est quasi nul ; le vrai capital investi est le temps du fondateur, amplifié par les IA. Si la niche « IDE minimaliste, local & accessible » trouve son public (hypothèse prudente : 2–2,5 % de conversion sur 12 000 actifs), l'activité atteint un revenu temps partiel solide (~33 k€ net/an) en an 3 — base saine pour, alors seulement, envisager une structuration plus lourde.

    Prochaine décision requise : date d'ouverture du repo public (T1) et choix définitif de la licence (GPL-3.0 recommandé).
