Votre code ne nous regarde pas.

MOTO Editor a été conçu autour d'une conviction simple : un éditeur de code n'a pas besoin de savoir ce que vous écrivez. 1. Objet, périmètre & responsable de traitement

La présente politique décrit la manière dont MOTO Editor — éditeur de code local, open source, développé en mode solo par son fondateur (Tomoushie, dépôt public github.com/Tomoushie/MOTO-Editor) — traite les données à caractère personnel dans le cadre de :

1.1 L'application MOTO Editor

  • Éditeur de code installé sur votre machine (Windows, .NET / MAUI / WinUI 3).
  • Moteurs IA locaux intégrés (Cortex, Neural, etc.).
  • Terminal intégré et services de compilation.

1.2 Le site & la communication

  • Site vitrine / landing page (GitHub Pages).
  • Liste d'attente / newsletter (adresse e-mail uniquement).
  • Support via GitHub Issues & Discussions.

Responsable de traitement : le fondateur du projet, joignable via le dépôt GitHub (Issues ou Discussions). Délégué à la protection des données : sans objet — le projet ne traite pas de données à grande échelle.

2. Le principe fondamental : local-first, zéro cloud

L'architecture même du produit rend la plupart des obligations de confidentialité… inutiles. Plutôt que de promettre de protéger vos données après les avoir collectées, MOTO Editor ne les collecte pas.

❌ CE QUE MOTO EDITOR NE FAIT PAS

· Aucun envoi de code source, fichier ou extrait de projet vers un serveur.

· Aucune télémétrie d'usage, analytics ou rapport d'erreur automatique.

· Aucun compte utilisateur, authentification ni licence en ligne.

· Aucun cookie, tracker publicitaire ou SDK tiers dans l'application.

✅ CE QUE MOTO EDITOR FAIT

· Lit et écrit uniquement dans les dossiers de votre projet (.moto/) et vos réglages locaux.

· Exécute l'IA en local via Ollama — vos prompts restent sur votre machine.

· Consulte Internet seulement si vous l'exigez explicitement (mises à jour, opt-in).

· Documente publiquement chaque exception éventuelle dans ses notes de version.

Les seules données écrites par MOTO Editor le sont sur votre disque. Elles ne quittent jamais votre machine sauf action volontaire de votre part (export, Git push, partage explicite). Le tableau ci-dessous est exhaustif à la version 1.0.

Base légale (RGPD)

4. Intelligence artificielle locale (Ollama)

Les fonctionnalités IA (suggestions, Cortex, analyse, génération de documentation) s'appuient par défaut sur des modèles exécutés localement via Ollama sur votre machine.

Données en jeu

  • Votre code et vos prompts sont soumis au modèle local.
  • Aucun flux réseau vers l'éditeur du projet MOTO.
  • Aucun stockage externe des requêtes ou des sorties.

Responsabilité partagée

  • Ollama est un logiciel tiers (politique propre : ollama.com).
  • MOTO Editor ne lui transmet rien d'autre que ce que vous éditez.
  • Si vous configurez un provider IA distant (opt-in explicite), vos requêtes transitent alors par ce service — c'est votre choix, et c'est documenté dans les réglages.

⚠️ Honnêteté sur les limites

  • Un agent local (PrivacyScanner) filtre les sorties IA pour détecter d'éventuelles fuites de données sensibles avant affichage.
  • Aucune IA n'est infaillible : ne collez jamais de secrets (clés, mots de passe) dans une conversation IA, même locale.

7. Vos droits (RGPD) & comment les exercer

Même si l'essentiel des données vit chez vous — et reste donc sous votre contrôle direct — le RGPD s'applique aux rares données que nous pourrions détenir (e-mail newsletter, tickets publics). Vous disposez des droits suivants :

DroitApplication concrète chez MOTO EditorDélai
Accès (art. 15)Obtenir la liste des données que nous détenons vous concernant (en pratique : votre e-mail newsletter).≤ 1 mois
Rectification (art. 16)Corriger une adresse e-mail erronée ou une donnée de ticket.≤ 1 mois
Effacement (art. 17)Suppression de la newsletter (lien en pied d'e-mail) ou demande directe. Les données locales vous appartiennent déjà.≤ 1 mois
Portabilité (art. 20)Export de vos données au format JSON/CSV sur demande.≤ 1 mois
Opposition (art. 21)Cesser tout envoi d'e-mails à tout moment, sans justification.Immédiat
Limitation (art. 18)Gel du traitement pendant l'examen d'une contestation.≤ 1 mois

7.1 Comment exercer vos droits

Voies de contact

  • GitHub : ouvrir une Issue sur le dépôt Tomoushie/MOTO-Editor avec le libellé privacy.
  • Pour une demande sensible, éviter les détails personnels dans le message public et demander un canal privé.

Réclamation

  • Si la réponse ne vous satisfait pas, vous pouvez saisir la CNIL (cnil.fr) ou l'autorité de protection de votre pays.
  • Nous préférons régler toute difficulté directement, en toute transparence.

NOTRE ENGAGEMENT DE DÉLAI

Réponse sous 30 jours maximum, en général bien moins. Chaque demande est tracée dans une Issue privée et sa résolution publiée anonymisée dans le devlog si elle améliore le produit. Dire vrai — même dans le juridique.

8. Sécurité, conservation, mineurs & modifications

Sécurité

  • Aucune base de données centralisée à attaquer : surface minimale.
  • Secrets jamais stockés en clair côté projet ; PAT exposé = révocation immédiate (règle interne).
  • Bac à sable (Sandbox) avec verrou pour les exécutions sensibles.
  • Signalement de vulnérabilité : Issue GitHub avec libellé security — réponse sous 7 jours.

Conservation

  • Application : données conservées tant que vous le souhaitez — effaçables à tout moment.
  • Newsletter : jusqu'à désinscription.
  • Tickets publics : selon votre propre gestion GitHub.

Mineurs

  • Aucune donnée n'est collectée sciemment auprès de mineurs de moins de 15 ans.
  • Le produit ne crée ni compte ni profil, ce qui réduit structurellement ce risque.

Modifications de la présente politique

  • Toute évolution sera annoncée dans les notes de version et sur le site.
  • La date de révision en tête de document fait foi.
  • Jamais de réduction silencieuse de vos garanties.
