# 🏍️ MOTO Editor

**Le premier IDE entièrement IA, local et hors-ligne.**

MOTO Editor est un éditeur de code cross-platform (.NET MAUI) doté d'une
intelligence interne autonome : il comprend ton projet, apprend ton style,
génère du code, documente, porte sur toutes les plateformes et répare
automatiquement — sans cloud, sans compte, sans modèle externe obligatoire.

> « Un IDE qui pense comme un senior, explique comme un prof,
> et code comme toi. »

---

## ✨ Pourquoi MOTO Editor ?

| Problème des IDE classiques | Réponse MOTO |
|-----------------------------|--------------|
| IA dépendante du cloud | **IA 100% locale** (Cortex + Neural + XENO) |
| Courbe d'apprentissage raide | **Modes Beginner / Tutor / No-Code** |

| Perte de contexte | **Time Machine** + **Cortex Memory** |
